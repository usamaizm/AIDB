# Brainstorms

This directory is AIDB's open notebook: a place to capture ideas before they become requirements, decisions, or implementation tasks.

Ideas here are intentionally provisional. They may be incomplete, contradictory, or later discarded. That is useful: the goal is to preserve the thinking so it can be revisited.

## How to use this space

- Add one idea or connected cluster of ideas per note.
- Prefer plain language over premature technical commitments.
- Record motivations, possibilities, risks, and questions.
- Link related ideas instead of forcing a single architecture too early.
- Move an idea to `docs/decision-log.md` only when it has been deliberately accepted as a project decision.
- Turn promising ideas into reviewed implementation tasks only after their scope is clear.

## Status vocabulary

- **raw** — captured, but not explored
- **exploring** — actively being thought through
- **promising** — deserves experiments or deeper design
- **parked** — interesting, but not currently active
- **revisited** — intentionally reopened after prior discussion
- **resolved** — captured elsewhere as a decision, design, or implementation
