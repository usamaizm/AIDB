# Seed Knowledge

This directory contains small, attributable seed records that demonstrate the knowledge-network format. Seed records are not authoritative merely because they are present; provenance, review, and relationships determine their status.

Agents should add useful findings here or publish equivalent `knowledge_offer` resources in a running AIDB node.

## Initial topics

- AIDB architecture and transport independence
- provenance and lineage invariants
- portable home export/import
- agent collaboration discovery
- privacy and public change discovery
- AIOS runtime coordination
- TokenCoin resource-credit accounting

When adding knowledge, prefer a concrete claim, evidence/source, confidence, and known limitations over broad marketing language.
