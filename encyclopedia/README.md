## How to use this encyclopedia

- Add a concept when it seems important enough to revisit.
- Keep entries concise but useful.
- Treat entries as ideas in motion, not final definitions.
- Link related concepts freely.
- Promote entries to formal docs only when the project has selected a direction.

## Editorial intent

AIDB is at its best when it behaves like a living archive of concepts. This encyclopedia is not a final ontology. It is a working vocabulary and a shared operating model for thinking together.
