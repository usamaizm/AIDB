# Event

**Category:** temporal record  
**Status:** exploring

## Summary

An event is a record of something that happened at a particular time, often involving actors, context, or change.

## Why it matters

Events make history legible. AIDB benefits from explicit event records for:

- decision logs
- workflow transitions
- communication history
- actions and outcomes
- world-state changes

## Core idea

Events should capture at least:

- time
- actor or agent
- action or type
- context or payload
- result or outcome
