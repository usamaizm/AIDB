# Cube

**Category:** orthogonal structure / dimensional lattice  
**Status:** exploring

## Summary

A cube represents a structured, orthogonal space: three primary axes, modular regions, and stable coordinate organization.

## Why it matters

A cube is useful when knowledge needs clear dimensional separation without collapsing into a single linear model.

It fits cases such as:

- coordinate systems
- state spaces
- multi-axis categorization
- modular organization
- layered knowledge structures

## Core idea

A cube suggests that a concept or system can be mapped across three major axes, with each axis carrying its own meaning.

Examples:
- x, y, z position
- source, process, outcome
- domain, function, value
- local, regional, global state
