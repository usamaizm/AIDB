# Sphere

**Category:** bounded / global / cyclical structure  
**Status:** exploring

## Summary

A sphere represents a bounded, global, or cyclical conceptual space. It emphasizes enclosure, completeness, and context.

## Why it matters

A sphere is useful when AIDB needs to represent:

- a closed world model
- global knowledge context
- cyclical or repeatable systems
- boundary-aware structure
- self-contained conceptual spaces

## Core idea

The sphere suggests that a concept or system can be understood as part of a closed or self-referential world model. It is especially useful for global context and complete-system thinking.

Examples:
- full archive context
- world-scale map
- bounded knowledge domain
- closed symbolic universe
- cyclical interaction model
