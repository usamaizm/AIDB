# Matrix

**Category:** 2D structured collection  
**Status:** common

## Summary

A matrix is a two-dimensional array of values arranged in rows and columns.

## Why it matters

Matrices are useful for tabular data, grids, and structured similarity spaces.

Examples:
- tables
- feature matrices
- coordinate grids
- spatial layers
- adjacency matrices

## Core idea

A matrix adds dimensional structure beyond a linear array. It allows relationships across two axes.
