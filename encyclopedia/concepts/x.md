# x

**Category:** scalar  
**Status:** raw / exploring

## Summary

`x` is the simplest idea unit: a single value, anchor, or scalar concept.

## Why it matters

Many systems begin with a single label or value before building structure. AIDB should support this simplest form without forcing all ideas into a complex object.

Examples:
- a keyword
- a concept label
- a score
- a document ID
- an atomic memory item
