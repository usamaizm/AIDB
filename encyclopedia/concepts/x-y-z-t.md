# x,y,z,t

**Category:** spacetime / process  
**Status:** raw / exploring

## Summary

`x,y,z,t` adds time to positional structure. This makes the record dynamic and event-oriented.

## Why it matters

Time is often the missing dimension in knowledge systems. AIDB should be able to record:

- moving objects
- trajectories
- events over time
- timestamps tied to location
- state transitions and workflows

Examples:
- location + timestamp
- route over time
- process state change
- event record in a world map
