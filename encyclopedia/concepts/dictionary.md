# Dictionary

**Category:** key-value memory  
**Status:** raw / exploring

## Summary

A dictionary is a mapping of named fields to values. It is one of the most natural ways to store structured metadata.

## Why it matters

Almost every concept or record eventually needs metadata: title, status, source, tags, version, and context.

Examples:
- concept metadata
- record provenance
- source notes
- task details
- agent state
