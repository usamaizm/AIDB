# Tensor

**Category:** multidimensional structure  
**Status:** advanced

## Summary

A tensor is a multidimensional array capable of representing data across more than two axes.

## Why it matters

Tensors are useful for:

- time-series data
- multi-channel observations
- embeddings and latent spaces
- scientific models
- complex event structures

## Core idea

A tensor generalizes arrays and matrices into higher-dimensional spaces.

Examples:
- time x latitude x longitude x sensor
- batch x sequence x feature
- channel x row x column
