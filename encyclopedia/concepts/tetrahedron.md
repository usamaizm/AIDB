# Tetrahedron

**Category:** minimal four-way structure  
**Status:** exploring

## Summary

A tetrahedron is a minimal, stable structure with four connected points. It is useful for representing balances, triangulations, and compact multi-way relations.

## Why it matters

A tetrahedron expresses the idea that some systems become most coherent when four elements are considered together.

This can model:

- four-part relations
- balanced structures
- triangulated understanding
- minimal stable networks
- layered concept relations

## Core idea

The tetrahedron is useful when a system cannot be reduced to a pair or a triangle without losing something essential. It suggests a stronger four-way interdependence.

Examples:
- source, process, output, feedback
- idea, evidence, context, outcome
- root, branch, relation, result
