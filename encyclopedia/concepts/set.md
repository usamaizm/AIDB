# Set

**Category:** unordered collection  
**Status:** common

## Summary

A set is an unordered collection of unique or related items.

## Why it matters

Sets are useful for:

- membership and uniqueness
- categories and clusters
- knowledge filters
- deduplicated concept groups

## Core idea

A set emphasizes membership rather than ordering.
