# Workflow

**Category:** process / transition model  
**Status:** exploring

## Summary

A workflow is an ordered set of actions or transitions through states.

## Why it matters

AIDB is not only a static archive. It should support processes such as:

- idea generation
- review and approval
- task execution
- knowledge promotion
- agent orchestration

## Core idea

A workflow records how a system moves from state A to state B, often with decisions and outcomes along the way.

## Open question

How much of a workflow should live in a simple sequence, and how much should become a richer graph or event system?
