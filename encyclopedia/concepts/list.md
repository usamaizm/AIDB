# List

**Category:** ordered collection  
**Status:** common

## Summary

A list is an ordered collection of items. The key feature is sequence, not necessarily homogeneous structure.

## Why it matters

Lists are useful for:

- action sequences
- chronological records
- notes and annotations
- queue-like structures
- ordered idea collections

## Core idea

Unlike an array, a list is more about ordering and collection semantics than numeric indexing or fixed shape.
