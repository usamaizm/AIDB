# Example AIDB Request Lifecycle

This directory demonstrates the complete path from an external AI proposal to an evaluated request, an internal task, and an accepted knowledge record.

These files are examples only. They do not grant permissions or authorize implementation.

## Lifecycle

```text
request.yml
  -> evaluation.yml
  -> task.yml
  -> knowledge-record.yml
```

The examples show that an AI can suggest work, while acceptance, task assignment, implementation, and knowledge promotion remain separate steps.
